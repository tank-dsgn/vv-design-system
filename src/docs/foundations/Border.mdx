# Border and Corner

## Corners

Two semantic tokens set the character of a project: `corner-control` for buttons and inputs, `corner-surface` for cards,
menus and modals. Small parts such as tags and checkboxes use the Tailwind scale directly.

<Unstyled><RadiusScale /></Unstyled>

## Borders

Borders are 1px hairlines in `color-border-default`, used when spacing alone isn't enough. See
[Colors](./?path=/docs/foundations-colors--docs) for the border tokens.
