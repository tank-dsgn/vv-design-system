# Motion

Motion confirms a change of state — a hover, a menu opening, a toast arriving. Nothing moves
on its own, nothing loops except a loading spinner, and nothing scrolls into view for effect.

## Speed

The same distance at each duration. The shorter it is, the smaller the change it confirms.

<Unstyled><MotionSpeeds /></Unstyled>

## Easing

One curve, `ease-out`: it starts fast, so the interface answers at once, and settles slowly. Compare it with a straight line
over the same time.

<Unstyled><MotionEase /></Unstyled>

## In use

The durations where they really work. Transitions name their properties; `transition: all` is never used.

## Reduced motion

Every component that moves carries its own `prefers-reduced-motion` rule. Under it transitions
are removed, and the spinner slows down rather than stopping — a frozen spinner reads as a hung
screen.
