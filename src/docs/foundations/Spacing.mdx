# Spacing & Size

The token number is the size in pixels: `space-16` is 16px, `space-40` is 40px. The steps come from Tailwind's spacing scale, without the ones off the 4px grid.

## Control heights

Buttons, inputs, selects and icon buttons share four heights, so any of them line up in a row.
`size-control-sm` (32px) is the default for dense product UI; `md` (40px) for forms;
`lg` (48px) for touch-first screens.
