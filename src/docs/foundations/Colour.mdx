# Colors

Every colour in the interface, as [tokens](./?path=/docs/foundations-tokens--docs): the Tailwind palette first, then the
semantic colours built on it, which components read.

## Brand

The project's own ramp. It points at one Tailwind ramp, `violet` here, and changing that one line recolours the
system. Semantic tokens read it as `brand-700`, not by the name of the ramp behind it.

<Unstyled><PrimitiveRamps only={["brand"]} /></Unstyled>
