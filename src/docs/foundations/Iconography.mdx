# Icons

Our own set plus the whole [Lucide](https://lucide.dev) library, free for any use under the ISC licence, in one outline style at one stroke. Rendered on a 20px grid at three sizes: **16px** inside compact
controls and badges, **20px** — the default — in buttons, inputs and navigation, **24px** for
standalone and empty-state icons. Icons take the colour of the text next to them, so they follow
every state and both themes without a colour prop.


```tsx
<Icon name="search" />                 {/* decorative: hidden from screen readers */}
<Icon name="warning" label="Warning" />  {/* the only carrier of meaning: named */}
```
