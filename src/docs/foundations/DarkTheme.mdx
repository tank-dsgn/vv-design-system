# Dark theme

Dark is a **mode**, not a second set of tokens. The token names stay the same; only their values
change under a `.dark` class. No component knows the theme exists — it reads
`color-background-primary` and gets whatever the current mode says.

```css
:root { --color-background-primary: var(--white); }
.dark { --color-background-primary: var(--neutral-950); }
```

The sun and moon button at the top right switches the whole page.

## What changes

- **Surfaces** move to `neutral-950` and `neutral-900` rather than pure black, so raised surfaces can
  still sit above the page.
- **Status colours** swap dark text on a pale fill for light text on a dark fill of the same hue.
- **Accent and status text** move to lighter steps of the same hue — the light-theme links and
  errors fall below 4.5:1 on a dark ground. Hover on a link goes lighter, not darker.
- **Disabled fills** go dark, so a disabled button no longer reads as enabled.
- **Shadows** keep their geometry and get a denser black; at 10% they would vanish.
- **Chart ramps** flip their anchor: the lowest value sits darkest, closest to the surface.
