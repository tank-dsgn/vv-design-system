# Breakpoints & Grids

Three page layouts on Tailwind's breakpoints. Columns stretch with
the viewport; the gutter stays 32px on desktop and tablet. Inside a layout, content blocks use the
same column counts — 12, 6, 5, 3 or 2 — so cards and forms line up with the page.
