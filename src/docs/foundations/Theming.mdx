# Theming

The system is meant to move between projects. Everything specific to one product sits in a short block at the top
of `tokens.css`: the Brand ramp, two corner values and the font. Change them and the same components fit the next
project.

Try it. Nothing below is restyled by hand; only those tokens change.

<Unstyled><ProjectTheme /></Unstyled>

## What changes, and what doesn't

- **Changes:** every brand-coloured thing, corners of controls and surfaces, the font.
- **Stays:** status colours, because red has to keep meaning failure on every brand; neutrals; spacing and type scales, which are Tailwind's.

A new brand ramp needs one check: white text on its step 700 must reach 4.5:1. Most Tailwind ramps pass.
Light ones such as yellow, lime and amber do not, so those need different steps.
